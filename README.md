# UX Review Blog

A modern and responsive blog landing page built using HTML and CSS only.

This project helped me practice responsive design, layouts, positioning, and building real-world UI sections.

---

## Features

- Clean and modern UI design
- Responsive layout for different screen sizes
- Navigation bar with mobile menu
- Hero section with bold typography
- Stylish cards and buttons
- Desktop and mobile support
- Pure HTML & CSS project

---

## Technologies Used

- HTML5
- CSS3
- Flexbox
- Media Queries

---

## What I Learned

While building this project, I learned that creating a beautiful design is not enough.

A website should also work correctly on different devices and screen sizes.

This project helped me understand:

- Responsive Design
- Media Queries
- Mobile-first thinking
- Layout troubleshooting
- UI spacing and positioning
